Mastodon Bungalow app

This app should contain two concepts:

1. MastodonSocialService

An implementation of a SocialService for integrating with Mastodon federated network instances.

2. MastodonServer

Implement a basic Mastodon server instance, for storing and referencing, using Apache Wildfire, which can be used to create P2P nodes which will be able to be run in background on the command line, headless to share playlists.
